# Intelligent Nutrition

Sistema e-commerce para la gestión y comercialización de productos de suplementación deportiva de Intelligent Nutrition.

## Estructura

- `backend/`: API y lógica de negocio.
- `frontend/`: aplicación web.
- `docker-compose.yml`: configuración para ejecutar los servicios de forma integrada.

## Tecnologías

### Backend

- NestJS
- Prisma
- PostgreSQL

### Frontend

- React
